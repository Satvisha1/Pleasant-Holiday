# Pleasant Holiday

A modern, scalable travel platform for exploring and planning trekking, tours, and adventure experiences across Nepal, Bhutan, Tibet, and India. 

The platform delivers a fast, intuitive, and content-driven experience, providing detailed itineraries, destination guides, and essential travel information for international travelers.

## 🚀 Features
* **Adventure Finder:** Easy navigation for travelers to explore regions.
* **Detailed Itineraries:** Structured day-by-day trekking schedules.
* **Inquiry System:** Built-in form using Resend to capture tourist bookings.
* **Responsive Design:** Optimized for mobile devices and desktop screens using Tailwind CSS.

## 🛠️ Tech Stack
* **Framework:** Next.js 16 (React 19)
* **Language:** TypeScript
* **Styling:** Tailwind CSS v4
* **Email Service:** Resend API
